# Message

Mit Message gestalten und automatisieren Sie Ihre Kommunikation mit Bewerbern und Interessenten:

* ✉️ Professionelle E-Mail-Vorlagen erstellen – passend zu Ihrem Styleguide
* 🔀 Automatisierte Workflows grafisch zusammenbauen, die auf Ereignisse reagieren

### Funktionsübersicht

* **✉️ Vorlagen**\
  Erstellen Sie E-Mail-Vorlagen im Design Ihres Styleguides – mit Variablen, Buttons und weiteren Inhaltsblöcken. → [Vorlagen](/message/vorlagen/index)
* **🔀 Flows**\
  Bauen Sie automatisierte Workflows grafisch zusammen: Ein Flow wird durch ein Ereignis ausgelöst, führt anschließend Aktionen wie das Versenden einer E-Mail aus und bietet definierte Ausstiegsmöglichkeiten. → [Flows](/message/flows/index)
