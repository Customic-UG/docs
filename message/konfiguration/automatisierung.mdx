## E-Mail

Unter **Einstellungen → Automatisierung → E-Mail** verwalten Sie die Absenderadressen, über die Ihre Organisation E-Mails versenden kann, z. B. für [Vorlagen](/message/vorlagen/index).

<img src="/images/message/konfiguration/e-mail.png"/>

### Standard-Adresse von osiro

Jede Organisation erhält automatisch eine bereits verifizierte Adresse nach dem Muster `ihre-organisation@out.osiro.email` (Kennzeichnung **osiro-Standard**). Diese Adresse können Sie ohne weitere Einrichtung sofort nutzen.

<Note>
Die Domain `out.osiro.email` wird von mehreren osiro-Kunden gemeinsam genutzt. Die Zustellbarkeit ist dadurch nicht garantiert. Für Versand unter eigener Marke und mit voller Kontrolle über die Zustellbarkeit empfiehlt sich eine eigene Domain.
</Note>

### Eigene Domain hinzufügen

Über **+ Hinzufügen** hinterlegen Sie stattdessen eine eigene Domain:

<Steps>
  <Step title="Domain hinzufügen">
    Tragen Sie Ihre eigene Domain ein. Freemail-Adressen wie gmail.com oder gmx.de funktionieren nicht, da Sie dort keinen Zugriff auf die DNS-Einstellungen haben.
  </Step>
  <Step title="DNS-Einträge setzen">
    Fügen Sie die angezeigten CNAME-Einträge bei Ihrem Domain-Anbieter hinzu (z. B. Namecheap, Cloudflare, IONOS).
  </Step>
  <Step title="Verifizieren">
    Klicken Sie auf **Erneut verifizieren**, sobald die DNS-Einträge gesetzt sind. Je nach Anbieter kann die Aktualisierung der DNS-Einträge einige Zeit in Anspruch nehmen.
  </Step>
</Steps>

<Warning>
Erst nach erfolgreicher Verifizierung können E-Mails über eine eigene Domain versendet werden, z. B. über [Vorlagen](/message/vorlagen/index) im [Nachricht-Baustein](/message/flows/nachricht).
</Warning>

## Häufige Fragen

<AccordionGroup>
  <Accordion title="Muss ich eine eigene Domain hinterlegen, um E-Mails versenden zu können?">
    Nein. Jede Organisation hat automatisch eine verifizierte Standard-Adresse (**osiro-Standard**) auf der Domain `out.osiro.email`, mit der sofort versendet werden kann. Eine eigene Domain ist optional und sinnvoll, wenn Sie unter Ihrer eigenen Marke versenden und die volle Kontrolle über die Zustellbarkeit haben möchten.
  </Accordion>
  <Accordion title="Warum lässt sich meine Freemail-Adresse nicht als eigene Versand-Domain verifizieren?">
    Für die Verifizierung müssen DNS-Einträge bei der Domain selbst gesetzt werden. Bei Freemail-Adressen gehört die Domain jedoch dem jeweiligen Anbieter – Sie haben dort keinen Zugriff auf die DNS-Verwaltung. Verwenden Sie stattdessen eine eigene Domain, deren DNS-Zone Sie selbst verwalten können.
  </Accordion>
</AccordionGroup>
