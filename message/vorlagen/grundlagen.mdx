## Überblick

In der Übersicht sehen Sie alle Ihre Vorlagen und können diese verwalten.

<img src="/images/message/vorlagen/grundlagen.png"/>

---

## Vorlagen verwalten

- **Neue Vorlage hinzufügen** – legt eine neue Vorlage an
- **Vorlage duplizieren** – erstellt eine Kopie einer bestehenden Vorlage
- **Vorlage löschen** – entfernt eine Vorlage dauerhaft

Beim Erstellen einer neuen Vorlage wird automatisch eine englische Beispiel-Vorlage angelegt, die Sie direkt im [E-Mail Editor](/message/vorlagen/email-editor) anpassen können.

---

## Häufige Fragen

<AccordionGroup>
  <Accordion title="Gibt es nur eine englische Vorlage?">
    Ja, aktuell ist keine deutsche Vorlage verfügbar. Sie können die englische Beispiel-Vorlage jedoch direkt im E-Mail Editor anpassen und übersetzen.
  </Accordion>
  <Accordion title="Kann ich eine bestehende Vorlage als Basis für eine neue E-Mail nutzen?">
    Ja, über **Vorlage duplizieren** erstellen Sie eine Kopie, die Sie unabhängig von der ursprünglichen Vorlage anpassen können.
  </Accordion>
</AccordionGroup>
