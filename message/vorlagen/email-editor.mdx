## Überblick

Sobald Sie eine Vorlage öffnen oder neu anlegen, gelangen Sie in den Bereich **Nachrichten → E-Mail**, in dem Sie die Vorlage bearbeiten.

<img src="/images/message/vorlagen/email.png"/>

---

## Blöcke

Folgende Blöcke stehen Ihnen zur Verfügung:

| Block | Beschreibung |
|---|---|
| **Text** | Fließtext-Block |
| **Überschrift** | Überschriften-Block |
| **Bild** | Bild-Block |
| **Trenner** | Visuelle Trennlinie |
| **Button** | Schaltfläche, z. B. für einen Call-to-Action |
| **Abschnitt** | Container zum Gruppieren mehrerer Blöcke |
| **Tabelle** | Tabelle mit 2, 3 oder 4 Spalten |

<Tip>Passende Kontaktfelder und Funnel-Variablen für Ihre Vorlage finden Sie unter [Einstellungen](/message/vorlagen/einstellungen).</Tip>

---

## Formatierung

Wie in gängigen Textverarbeitungsprogrammen stehen Ihnen folgende Formatierungsoptionen zur Verfügung:

- Fett, Kursiv, Unterstrichen, Durchgestrichen
- Rückgängig / Wiederholen
- Schriftgröße
- Ausrichtung

---

## Vorschau

Sie können die Vorlage sowohl in der **Desktop-** als auch in der **mobilen Ansicht** als Vorschau betrachten.

---

## Test senden

Über **Test senden** können Sie die Vorlage an eine selbst gewählte E-Mail-Adresse senden, um sie vor dem Einsatz zu überprüfen.
