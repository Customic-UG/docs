## Überblick

Der Basic Button ist der Standard-Button für Aktionen innerhalb eines Steps – etwa um zum nächsten Step zu wechseln, ein Formular abzusenden oder auf eine externe URL zu verlinken. Die meisten anderen Blöcke, die intern einen Button anzeigen (z. B. Multi-Select), verwenden denselben Basic Button.

<img src="/images/convert/funnel-editor/blocks/actions/basic-button.png"/>

<Tip>Einsatz für jede Weiterleitung oder jeden Absende-Vorgang innerhalb eines Steps. Über den Regeln-Tab lassen sich zusätzlich [Regeln](/convert/funnel-editor/conditions) hinterlegen, die z. B. steuern, zu welchem Step der Button führt.</Tip>

- **Bezeichnung** – der auf dem Button angezeigte Text
- **Beschreibung** – optionaler unterstützender Text
- **Symbol** – optionales Icon auf dem Button
