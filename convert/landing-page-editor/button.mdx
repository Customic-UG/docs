## Überblick

Viele Blöcke enthalten einen oder mehrere Buttons. Die Konfiguration ist bei allen Buttons gleich aufgebaut.

---

## Einstellungen

| Einstellung | Beschreibung |
|---|---|
| **Aktiviert** | Blendet den Button ein oder aus. |
| **Button-Text** | Der auf dem Button angezeigte Text. |
| **Typ** | Primär, Sekundär oder Text – reine Optik, keine Auswirkung auf die Funktion des Buttons. |
| **Link** | Ziel des Buttons: **URL** (verweist auf eine externe oder interne Adresse) oder **Abschnitt** (verweist auf einen Abschnitt innerhalb der Landing Page). |
| **Link-URL** | Die Ziel-URL, wenn bei Link "URL" ausgewählt ist. |
| **Symbol** | Optionales [Icon](/convert/medien/icons) auf dem Button. |
| **Symbol-Position** | Ob das Symbol vor oder nach dem Button-Text angezeigt wird. |

<Tip>Der Link eines Buttons sollte in der Regel auf einen [Funnel](/convert/landing-page-editor/funnel) verweisen – dort soll der Besucher am Ende hin.</Tip>
