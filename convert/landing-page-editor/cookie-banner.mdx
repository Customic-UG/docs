## Überblick

Der osiro Cookie-Banner ist ein datenschutzkonformer Consent-Banner mit drei Kategorien: **Notwendig**, **Analyse** und **Werbung**. Die Zustimmung wird im Cookie `osiro_cc` gespeichert.

Platzhalter – kurze Einordnung, wann/warum Kunden den Banner statt Usercentrics nutzen würden.

## Tracking mit Google Tag Manager

Der Banner sendet automatisch die nötigen Consent-Signale (Google Consent Mode v2) an `window.dataLayer` – an der Landing Page selbst müssen Sie dafür nichts einstellen. Diese Signale nutzt z. B. das Tracking Ihres Funnels (Google Tag Manager Container, Meta-Pixel), um erst nach Zustimmung des Besuchers zu laden.

Wie Sie das in Ihrem Google Tag Manager Container einrichten, erklärt der Artikel [Tracking mit Consent Mode absichern](/convert/funnel-editor/consent-mode).

## Externe Scripts blockieren

Scripts mit `type="text/plain"` und einem `data-category`-Attribut werden von osiro so lange blockiert, bis die jeweilige Kategorie akzeptiert wurde – erst dann wird das Script ausgeführt.

```html
<!-- Wird erst nach Zustimmung zur Kategorie "analytics" ausgeführt -->
<script type="text/plain" data-category="analytics" data-src="https://example.com/analytics.js"></script>

<script type="text/plain" data-category="analytics">
  // Inline-Code, gleiche Regel
</script>
```

Zusätzliche Attribute:

| Attribut | Wirkung |
|---|---|
| `data-service="Google Analytics"` | Bindet das Script an einen einzelnen Schalter im Präferenzen-Modal statt an die gesamte Kategorie |
| `data-src` statt `src` | Verhindert, dass der Browser die Datei bereits vor der Zustimmung lädt |
| `data-category="!analytics"` | Führt das Script aus, wenn die Kategorie **abgelehnt** wird (Escape-Hatch, selten benötigt) |

Weiterführende Dokumentation: [cookieconsent.orestbida.com/advanced/manage-scripts.html](https://cookieconsent.orestbida.com/advanced/manage-scripts.html)

## Häufige Fragen

<AccordionGroup>
  <Accordion title="Kann ich Cookie-Banner und Usercentrics gleichzeitig nutzen?">
    Nein, die beiden Integrationen schließen sich gegenseitig aus. Aktivieren Sie eine der beiden, wird die andere automatisch deaktiviert.
  </Accordion>
  <Accordion title="Muss ich den Banner für jede Landing Page einzeln aktivieren?">
    Ja, die Einstellung liegt unter Einstellungen → Integrationen der jeweiligen Landing Page und gilt nur für diese eine Seite.
  </Accordion>
  <Accordion title="Was passiert mit Scripts, die weder data-category noch data-service besitzen?">
    Sie laufen ganz normal wie jedes andere Script auf der Seite – nur Scripts mit `type="text/plain"` und `data-category` werden vom Cookie-Banner blockiert und erst nach Zustimmung ausgeführt.
  </Accordion>
</AccordionGroup>
